# Sider 主控开发与集成回归报告

验证日期：2026-10-08，北京时间。最终网络验收完成于 11:27。

## 结论

已生成服务端与 Claude Code 配置模板，并在 Deno、Bun 两套实现中落地经过上游探测支持的 Sider 主控工具循环。最终验收全部通过：357 项确定性测试、135 项 HTTP 集成用例及两项真实 Claude Code 文件验证，类型检查和构建通过。全部要求的集成用例无失败、无上游受限、无以跳过代替通过。

本次“100%”指下面列明的验收集合，不代表所有上游模型、所有输入、视觉能力或完整 PPT 成品质量均已验证。

## 实证前提

1. 2026-10-07 的 57 次 Sider 探测已确认 Opus 5.5／Sonnet 5.5 能按明确文本契约生成 Read、Write、MCP 和嵌套参数，处理失败结果并收敛。已测原生 Anthropic 自定义工具提交方式被拒绝。
2. 开发前补测 StoreContent→本地实际保存及 SHA-256→WriteFromRef，两模型共四轮校验全部通过，没有只要求模型自称支持。
3. 开发前补测“规范片段→完整工具定义→增量任务指令”，两模型均按随机唯一路径正确调用 Read。
4. 实际服务集成使用 39,111 字符规范及完整工具定义，验证分段登记后工具选型及路径正确。
5. 实际 Claude Code 2.1.195 完成 Read→Write，检查了客户端执行反馈、新输出文件、JSON 项数和字节一致性。

上游探测按串行、流结束后间隔至少 12 秒执行。本次模型标识来自 Sider 事件，不能独立证明底层权重身份；没有通过压力测试推断最高吞吐。

## 已落地行为

- `SIDER_CONTROLLER=true` 进入独立主控路径，Sider 负责规划、创作、工具选择和结果判断。客户端执行实际工具，工具结果完整回到同一会话。
- 严格 JSON、声明工具名单和 JSON Schema 校验，覆盖真实 Claude Code 的 2020-12 方言；禁止类型转换、删字段、填默认值或猜测修补副作用参数。
- 无 cid 的工具续轮通过代理生成的唯一工具 ID 查找任务。Deno KV／Bun SQLite 保存真实 Sider cid、父消息、正文引用、待执行工具和检查点；两个独立服务进程的迁移续轮已实际验证。
- 大规范和工具定义完整分段登记，单次新增输入默认不超过 14,000 字符，执行前提供可容纳的完整 schema，参数纠正重发相关工具定义。
- StoreContent 本地保存完整正文，WriteFromRef 校验归属及 SHA-256 后展开成客户端真正的 Write，正文不经过 GLM 重写。
- 已实际复现并修复 Read→Write 复制重复转义；针对已测完整 JSON 行号展示，代理保存源正文引用，禁止模型再生成原文。
- 正文仅保存或 Write 校验失败时不能报告完成；客户端 Write 失败必须继续处理，不能把自述当成功反馈。
- Sider 使用真实上游字节空闲期限和独立总期限。Bun 服务端空闲期限明确为 255 秒，主控 SSE 每 5 秒 ping，避免实际复现的 10 秒竞争断连。
- 解析新版统一 `tool_call` 原生事件、HTTP 400 正文中的 603，并保留正确错误分类。主控循环默认禁用服务端原生工具，避免隐藏执行副作用。
- 明确连接建立失败仅允许一次有界重试；SSE／正文读取失败和超时不盲目重试。额度错误按上游提示保存冷却，检查点保留。
- CI 补充 Bun 单元回归和真实 Claude Code 验证入口的类型检查。

当前已验证工具链路由本地转换即可完成，因此主控模式没有额外调用 GLM 去重新规划、重写正文或接管会话。原有 GLM 兼容后端配置和混合路由继续保留；未获得实证支持的模型参数猜测没有作为主控回退实现。

## 首轮失败与修正

失败记录没有从验收历史中删除；最终结果来自修正后的重跑。

| 实际失败 | 根因／发现 | 修正及验证 |
|---|---|---|
| 五项基础重现全部失败 | 纯工具结果丢失、未知工具及坏类型可还原、统一事件漏读、HTTP603分类丢失 | 五项修复后通过，并纳入318项回归 |
| 首轮 Deno 主控7/9 | 建立 TCP 连接失败；长规范之后不再稳定使用先前工具定义 | 有界连接重试；规范先登记、执行前提供完整 schema，最终10/10 |
| 实际 CLI 没有产生 Write | 真实客户端使用2020-12 schema；引用展开校验失败后模型自称完成 | 方言校验、明确失败反馈及未提交Write的完成守卫 |
| 后续 CLI 写入损坏 JSON | 模型在复制源正文时再次转义换行及反斜杠 | Read展示原文由本地保存引用；两运行时真实字节比较通过 |
| 首轮 Bun 主控9/10 | Bun默认10秒空闲与10秒ping竞争断连 | 255秒服务端期限、5秒ping；真实11.5秒HTTP用例及最终10/10 |
| 原有 Bun 会话测试存在降级通过 | 没有cid就返回pass，没有验证第二轮 | 无cid时发完整历史，实际检查姓名和年龄均保留；27/27重新通过 |

本次未修改生产平台环境变量；配置模板已生成。用户原有 `deno/.env.example` 的模型修改保留，不纳入本次提交范围。

## 验证边界

- 未将未知视觉能力伪装成支持；主控模式明确拒绝图片输入，包括工具结果内的图片。没有生成或视觉验收完整PPT成品。
- Read展示正文无法提供原文件的全部编码、CRLF和末尾换行信息；本次逐字复制针对已测UTF-8／LF JSON格式。任意文件的原始字节复制应由客户端文件复制工具完成。
- 没有证实 Sider 支持 Anthropic thinking预算、原生自定义函数协议或不限量并发／额度。
- 没有证实所有已登记模型都具备同等工具契约能力；本次主控实证重点为Opus5.5和Sonnet5.5。
- Sider token是字符估算，包含内部登记、保存及纠正轮次；Claude Code展示的厂商价格估算不能视作实际Sider／GLM计费。
- 本地KV／SQLite跨进程测试已通过；生产Deno Deploy仍须关联可用KV，并核验平台请求期限。配置和代码不会自动创建生产数据库。
